Try Hard · installer

Connect the FM-1 to this computer with a USB data cable, then press Install. Chrome or Edge (Web MIDI with SysEx). Don't unplug it while it writes; it restarts into Try Hard by itself.

Going back: any other firmware, or M-VAVE's own, installs over Try Hard as usual, for example from the FM-1 Firmware Hub. If an update is cut off, switch the FM-1 on holding OCT−: the USB rescue, where Install works again. Installing firmware is at your own risk.
