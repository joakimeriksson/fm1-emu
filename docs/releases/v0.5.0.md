**Firmwares on the new felucca-bsp play again** in fm1-live and the plugin: FRASIL 3.3, AMB-1
1.3.2, CTL-1 1.0.3, CHOPPAH 0.99 and Polly 0.6.2 booted, drew their screens and stayed silent in
0.4.0. The JIT is faster on the firmwares that use both cores, and fm1-live gets a sharp window on
Windows. The page,
[joakimeriksson.github.io/fm1-emu](https://joakimeriksson.github.io/fm1-emu/), needs no download
and is always the latest.

Intel Macs: the JIT runs there too, built from source (`tools/build_plugin.sh`, `cargo build
--release`); an Intel macOS download is still to come.

**fm1-live** plays a firmware package: `./fm1-live --fwsc felucca.fwsc`. The packages: the
community firmwares on [the FM-1 Firmware Hub](https://thefirmwarehub.com/) (and the list on
the page, with each author's link), or M-VAVE's own `FM-1.fwsc`. The computer keyboard plays
the keys, and so does every MIDI input. On Linux it needs ALSA and X11:
`sudo apt install libasound2 libx11-6 libxkbcommon0 libxcursor1 libxrandr2 libxi6` (Ubuntu 24.04
and later: `libasound2t64` in place of `libasound2`). Each archive's `README.txt` has the rest.

**Not signed:** macOS blocks the downloads until you allow them. For the plugin, after copying
it (as `INSTALL.txt` says):

```sh
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/FM-1.component ~/Library/Audio/Plug-Ins/VST3/FM-1.vst3 ~/Library/Audio/Plug-Ins/CLAP/FM-1.clap
```

and for fm1-live, in its folder: `xattr -d com.apple.quarantine fm1-live fm1-emu`. The Windows
build is unsigned too; Windows hosts load it as it is.

## What's new since 0.4.0

- **Firmwares on the new felucca-bsp make sound** (#153): its audio driver checks that the audio
  PLL reads what the bootloader leaves there before it starts the audio, and the emulated chip
  now boots with those values. FRASIL 3.3, AMB-1 1.3.2, CTL-1 1.0.3, CHOPPAH 0.99 and Polly
  0.6.2 were silent in 0.4.0 (#170).
- **Firmwares built with the open pi32v2 LLVM toolchain** no longer freeze when they save an
  unusual set of registers (#163, justifiably), nor on memory words shifted by a register
  (#149: BB1 2.1.1 halted on it).
- **Faster on two cores.** Natively, the second core's polling loops now run in compiled code
  and stop inside a block without leaving it (#154, #156: DUELL 1.3x to 2.2x real time, and
  1.7x faster in the browser); block moves compile inline (#155: Purple Monkey 4.1x to 6.4x). In
  the browser, the JIT's regions run without copies (#136, jamminstein: Bubba Machine 0.82x to
  1.22x, Ravel 1.9x to 2.8x, LOOM-8 3.7x to 5.1x), and a core that finds a lock held hands the
  machine to the core holding it (#115, jamminstein).
- **The plugin's lead over the host is a setting** (#144): 23 ms as before, or 12 or 6 ms for a
  shorter latency on a fast machine.
- **fm1-live on Windows** opens a sharp window at any display scaling that fits the screen
  (#164, bask209).
- **Record a WAV:** F3 in fm1-live, a Record button in the plugin (#167, bask209). The takes
  go to `Music/fm1-emu` in your home folder.
- **fm1-live `--record DIR`** writes the panel's frames and the audio for a video (#91,
  DimmKirr; `tools/bench_video.sh` makes the MP4).
- **The page:** it lists the Hub's new firmwares the day they appear, marked as not yet run here
  (#146); `?package=URL&name=` plays a package from another site (#158, konsumer); the catalog
  has 158 firmwares, with CHOPPAH, B3 Organ and VEFFBOX new (#141 profikid, #143, #145, #150).
- **Android x86-64** builds get the native JIT (#171, GenericJam).
- **`FM1_STRICT=1`:** core 1 pays the full cost of its instructions (#152).
- **Contributors this release:** jamminstein, bask209, DimmKirr, konsumer, justifiably,
  GenericJam, profikid.
