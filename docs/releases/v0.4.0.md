**The plugin comes for Windows** (VST3 and CLAP), the emulator is faster everywhere, with FM-1 Dock
eight times faster, and more firmwares run: the SMK-37 Pro's stock-based mods, Bubba Machine's
FreeRTOS on both cores, COSMOS, Ravel. The page,
[joakimeriksson.github.io/fm1-emu](https://joakimeriksson.github.io/fm1-emu/), needs no download
and is always the latest.

| `fm1-plugin-0.4.0-macos-arm64.zip` | The plugin (AU, VST3, CLAP): Macs with Apple silicon, macOS 11 or later. Its `INSTALL.txt` says where each file goes. |
| `fm1-plugin-0.4.0-windows-x86_64.zip` | The plugin (VST3, CLAP): Windows 10 or later, x86-64. New. Its `INSTALL.txt` names the folders; keep both files, the VST3 loads the CLAP. |
| `fm1-emu-0.4.0-macos-arm64.tar.gz` | fm1-live and fm1-emu, Macs with Apple silicon (with the JIT) |

| `fm1-emu-0.4.0-linux-x86_64.tar.gz` | fm1-live and fm1-emu, x86-64 Linux (with the JIT) |

Intel Macs: the JIT runs there too, built from source (`tools/build_plugin.sh`, `cargo build
--release`); an Intel macOS download is still to come.

**fm1-live** plays a firmware package: `./fm1-live --fwsc felucca.fwsc`. The packages: the
community firmwares on [the FM-1 Firmware Hub](https://thefirmwarehub.com/) (and the list on
the page, with each author's link), or M-VAVE's own `FM-1.fwsc`. The computer keyboard plays
the keys, and so does every MIDI input. On Linux it needs ALSA and X11:
`sudo apt install libasound2 libx11-6 libxkbcommon0 libxcursor1 libxrandr2 libxi6` (Ubuntu 24.04
and later: `libasound2t64` in place of `libasound2`). Each archive's `README.txt` has the rest.

**Not signed:** macOS blocks the downloads until you allow them. For the plugin, after copying
it (as `INSTALL.txt` says):

```sh
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/FM-1.component ~/Library/Audio/Plug-Ins/VST3/FM-1.vst3 ~/Library/Audio/Plug-Ins/CLAP/FM-1.clap
```

and for fm1-live, in its folder: `xattr -d com.apple.quarantine fm1-live fm1-emu`. The Windows
build is unsigned too; Windows hosts load it as it is.

## What's new since 0.3.0

- **The plugin on Windows:** VST3 and CLAP, tested and validated on every release, with a guide
  for Waveform Free in the README. The file dialog opens on top of the host's window. On a Mac,
  a firmware the plugin may not read (macOS keeps a DAW's plugin host out of Desktop, Documents,
  Downloads and iCloud Drive) now says so, and where the file works.
- **More firmwares run:** the SMK-37 Pro's stock-based mods (their patch area); Bubba Machine,
  whose FreeRTOS runs on both cores (the cores' hardware lock, and a core that sleeps on `idle`
  until its interrupt); COSMOS, whose core 1 faults on the chip and is let go
  (`--cpu1-survives` in fm1-live); Ravel, whose hot loop runs from RAM (its code and the
  firmware's no longer evict each other).
- **Faster.** Natively, by CPU time per block against 0.3.0 on this Mac: Felucca -8 %, X0X -4 %,
  Ghoulbox -12 %, 386DX -10 %, Melodee -7 %, FM-1 Dock -87 % (a software delay on its second
  core ran as 60 million blocks a second; it runs in one go now). In the browser the heaviest
  firmwares gained the most: Bubba Machine 0.62x to 1.13x real time, Ravel 0.74x to 0.91x,
  LOOM-8 2.87x to 3.31x, DUELL 0.83x to 1.00x, FM-1 Dock at real time, with the FPU and most
  other instructions compiled inline and core 1 running whole stretches in compiled code.
- **The chip's hardware DSP units:** the FFT / vector unit, the hardware EQ and the sample-rate
  converter, measured on a real FM-1 and modelled (FM-1 Dock's master EQ runs on it).
- **The chip's resets:** the watchdog and `PR_PWR` reset the emulated chip, so a firmware's
  hang recovery can be tested.
- **A realistic mode for firmware authors, `FM1_STRICT=1`:** the LCD's transfers take their time
  at the SPI clock, each instruction its measured cost, the flash cache its misses, and
  misaligned accesses fault, all measured on a real FM-1; the CPU's guards (PC limits, the NULL
  page) are always on. The default emulator is unchanged.
- **USB:** the computer can record the firmware's USB audio (`FM1_USB_WAV`), and a tail call out
  of an if-block no longer holds interrupts off (FM-1 Dock's USB audio missed packets for it).
- **The page:** `?flash=` and `?script=` open a firmware with flash contents and an input script
  laid over it, which is how FM-1 Dock's catalog opens each module with one click.
- **Fixes:** the stock FM-1 firmware's SPI1 interrupt turns off as it should (eubide); the JIT
  on Intel Macs (eubide); a countdown loop on the second core stops where the interpreter does.
- **Contributors this release:** jamminstein (the second core, the wasm JIT's speed, the SMK-37
  Pro's patches), eubide (Intel Macs, SPI1).
