**fm1-live comes for Windows**, **Polly's band and Melodee's factory sounds** play from their packages
alone, the emulator can be **the newer FM-1 with its other flash chip**, and the page lists **202
firmwares**, refreshed from the Hub. The page,
[joakimeriksson.github.io/fm1-emu](https://joakimeriksson.github.io/fm1-emu/), needs no download
and is always the latest.

## Highlights

- **fm1-live for Windows**: double-click it and pick a firmware; F4 opens another.
- **Lower latency**: 12 ms on Windows, with WASAPI exclusive mode.
- **Packages install whole**: Polly's band plays, and Melodee boots with its factory sounds.
- **The newer FM-1's flash chip** (UC25HQ80): `?chip=uc25hq80` shows which firmwares save on it.
- **202 firmwares on the page**, refreshed from the FM-1 Firmware Hub.
- **A faster panel**, drawn three to four times cheaper.
- **The FM-1 Sampler over USB** in `fm1-live --usb`.

Intel Macs: the JIT runs there too, built from source (`tools/build_plugin.sh`, `cargo build
--release`); an Intel macOS download is still to come.

**fm1-live** plays a firmware package: `./fm1-live --fwsc felucca.fwsc`, or on Windows a
double-click, which asks for one. The packages: the community firmwares on
[the FM-1 Firmware Hub](https://thefirmwarehub.com/) (and the list on the page, with each author's
link), or M-VAVE's own `FM-1.fwsc`. The computer keyboard plays the keys, and so does every MIDI
input. On Linux it needs ALSA and X11:
`sudo apt install libasound2 libx11-6 libxkbcommon0 libxcursor1 libxrandr2 libxi6` (Ubuntu 24.04
and later: `libasound2t64` in place of `libasound2`). Each archive's `README.txt` has the rest.

**Not signed:** macOS blocks the downloads until you allow them. For the plugin, after copying
it (as `INSTALL.txt` says):

```sh
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/FM-1.component ~/Library/Audio/Plug-Ins/VST3/FM-1.vst3 ~/Library/Audio/Plug-Ins/CLAP/FM-1.clap
```

and for fm1-live, in its folder: `xattr -d com.apple.quarantine fm1-live fm1-emu`. The Windows
builds are unsigned too: Windows may ask once before it runs `fm1-live.exe` (More info, Run anyway).

## What's new since 0.5.0

- **fm1-live and fm1-emu for Windows** (#166, bask209): a double-click asks for a firmware, F4
  opens another (keeping how it runs, not the old firmware's flash), and a firmware that fails to
  load keeps its error on screen.
- **Lower latency in fm1-live** (#165, bask209): 12 ms of audio ahead by default on Windows (50 ms
  elsewhere, as before), growing on underruns and settling at what the device needs;
  `--latency MS`, `--buffer FRAMES`, and `--exclusive` for WASAPI exclusive mode on Windows.
- **A package is the whole install again** (#175): packages now carry the data their update
  loader writes after the app, and the emulator lays it into the flash as an install does. Polly
  0.6.4's band plays (it ran on the screen and played nothing), and Melodee 1.6.1 boots with its
  factory sounds (it asked to be installed again).
- **The newer FM-1's flash chip** (#177): FM-1 units sold since autumn 2026 carry a UC25HQ80 in
  place of the Puya. `?chip=uc25hq80` on the page and `--flash-chip uc25hq80` in fm1-live and
  fm1-emu run a firmware on it. Of the firmwares that save, most save nothing there: their
  authors can now see that, and check a fix.
- **202 firmwares on the page** (#178): 76 moved to newer packages and 45 are new, each played
  with the JIT and interpreted before it is listed; `tools/catalog_refresh.py` does it, and the
  list with every author is in [docs/FIRMWARES.md](../FIRMWARES.md) (#179).
- **The panel is drawn three to four times cheaper, the same pixels** (#176, eubide), and
  fm1-live's emulation no longer waits for the window to draw (#172, eubide).
- **USB interrupts** (#169, pcace): the FM-1 Sampler talks to the computer in `fm1-live --usb`.
- **Contributors this release:** bask209, eubide, pcace.

**If you use fm1-live's `--flash FILE`** with Melodee 1.6.1 or Polly 0.6.4: a file saved by 0.5.0
holds the flash without their data, and restoring it erases that data again. Start once without
it (or with a new file). Saves on the page and in the plugin are not affected.
